Design System

Las piezas base — antes de tocar una sola pantalla completa

Este es el kit de construcción: color, tipografía, botones, tarjetas y componentes, con sus estados (default, hover, active, focus, disabled). Todo sale de la dirección creativa ya aprobada. Cuando apruebes esto, seguimos con Home completa.

Colores

La paleta aprobada, con su rol asignado.

Regla de uso del naranja: es el color de acción/antojo. El botón "Pedir por WhatsApp" debe seguir siendo el elemento naranja más evidente de toda la interfaz — el resto de usos (chips activos, badges, detalles) son secundarios y controlados, nunca compiten en protagonismo con el CTA de compra.
